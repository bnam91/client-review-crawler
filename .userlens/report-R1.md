## 🚫 검증 후 제외 (버그 아님 — 다음 라운드 재발견 방지)

| 증상 | 제외 사유 |
|---|---|
| 창 아래쪽이 흰색으로 비어 보인다 | ★**계측기가 만든 증상.** puppeteer 기본 viewport(800×600)가 화면을 덮어써서 생김. `defaultViewport:null`이면 gap=0. 숫자: 덮어쓸 때 inner 801×600/outer 480×860, null이면 inner 467×828/bodyH 828 |
| 라이선스 모달이 창 밖으로 잘린다 | 재현 안 됨. 네이티브 캡처에서 모달은 창 중앙에 온전하다. 처음 보고된 스샷이 «캡처 범위»가 잘린 것이었다 |
| 한글이 깨진다 | 대체문자 0개, 정상 |
| 타이틀바 아이콘 깨짐 | 버그 맞지만 **이미 확정된 기존 건**(icon.ico 256 한 장) — 중복이라 재채집 안 함 |
| 라이선스가 안 막힌다 | 이미 확정된 기존 건 — 별건 보관 중 |
