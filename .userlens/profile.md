# 리뷰크롤러 체감 명세 (userlens)

## ⚠️★이 앱을 CDP로 볼 때의 절대 규칙 (2026-09-20 실측으로 박음)

**반드시 `defaultViewport: null` 로 붙는다.**

안 그러면 puppeteer가 화면을 **800×600으로 덮어쓴다**. 창은 480×860인데 문서만 600이 되어
**아래쪽이 흰색으로 남는다.** 실제로 이것 때문에 「화면이 깨졌다」는 오보가 났다 — 숫자 대조:

| 연결 방식 | inner | outer | bodyH | gap |
|---|---|---|---|---|
| 기본값(덮어씀) | 801×600 | 480×860 | 600 | 있음 → **흰 여백** |
| `defaultViewport:null` | 467×828 | 480×860 | 828 | **0** |

⇒ ★**계측기가 증상을 만든다.** 화면 문제를 볼 때 관찰은 «네이티브 캡처»로 교차확인할 것.

## ⚠️ 미니05에서 앱 띄우는 법 (실측)

- ⛔`ssh`로 직접 실행하면 **세션0**이라 창이 없고 몇 분 뒤 죽는다.
- ✅`schtasks /IT`(세션1)로 띄운다 — `schtasks /run /tn RC05_APP`. 안정적으로 유지된다.
- 네이티브 캡처: `capfront.ps1`(창만) / `capwin.ps1`(전체화면) — 스케줄러로 실행.

## 풀플로우 경로 (RUN의 대본)

1. **첫 대면** — 앱을 처음 켠 화면. 무엇을 하라는지 알겠는가.
2. **라이선스 화면** — 등록 안내가 이해되는가. 막히는가.
3. **URL 입력** — 상품 주소를 붙여넣는다. 어떤 형태를 받아주는가.
4. **옵션 선택** — 수집 개수 / 정렬 / 이미지 / 안정 수집 / 저장 경로.
5. **수집 실행** — 시작 후 진행 표시가 읽히는가. 얼마나 걸릴지 알겠는가.
6. **차단 대면** — 네이버가 로그인·보안확인을 요구할 때 무엇을 하라고 말해주는가.
7. **결과 확인** — 저장된 파일을 찾을 수 있는가. 몇 건인지 믿을 수 있는가.
8. **실패 경험** — 0건으로 끝났을 때 원인을 알 수 있는가.
